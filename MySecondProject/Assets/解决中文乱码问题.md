# 解决TextMeshPro中文乱码问题

## 问题原因

字体资源 `SourceHanSansSC-ExtraLight SDF` 的 `AtlasPopulationMode` 设置为 `Static`（静态模式），这意味着字体atlas中只包含创建时预定义的字符。当文本中包含atlas中没有的字符时，就会显示为乱码。

## 解决方案

### 方法1：将字体资源改为动态模式（推荐）

1. 在Unity编辑器中，找到字体资源：
   - `Assets/TextMesh Pro/Resources/Fonts & Materials/SourceHanSansSC-ExtraLight SDF.asset`

2. 选中该资源，在Inspector面板中找到 `Generation Settings` 部分

3. 将 `Atlas Population Mode` 从 `Static` 改为 `Dynamic`

4. 点击 `Apply` 保存设置

5. 重新运行游戏，TextMeshPro会自动为缺失的中文字符生成glyph

### 方法2：重新生成字体资源，包含所有中文字符

1. 在Unity编辑器中，打开 `Window` → `TextMeshPro` → `Font Asset Creator`

2. 在 `Source Font File` 中选择 `SourceHanSansSC-ExtraLight.otf`

3. 在 `Character Set` 中选择 `Unicode Range (Hex)`

4. 输入中文字符范围：`4E00-9FFF`（常用汉字）

5. 或者选择 `Custom Characters`，输入需要的中文字符：
   ```
   登录失败成功！请输入用户名密码
   ```

6. 点击 `Generate Font Atlas` 生成字体atlas

7. 点击 `Save` 或 `Save as...` 保存字体资源

8. 确保保存的字体资源路径为：`Assets/TextMesh Pro/Resources/Fonts & Materials/SourceHanSansSC-ExtraLight SDF.asset`

### 方法3：在Prefab中直接设置字体（临时方案）

1. 打开 `Assets/Prefabs/LoginUi.prefab`

2. 选择 `TitleText` GameObject

3. 在Inspector中找到 `TextMeshProUGUI` 组件

4. 将 `Font Asset` 设置为支持中文的字体（如果已有其他中文字体资源）

5. 同样设置输入框的字体

## 验证

修改后，重新运行游戏，检查：
1. Unity Console中应该看到字体设置成功的日志
2. UI中的中文应该正常显示，不再乱码

## 注意事项

- 动态模式会占用更多内存，因为需要动态生成字符
- 静态模式性能更好，但需要预先包含所有需要的字符
- 如果使用动态模式，建议设置合理的atlas大小（如2048x2048）
