# Change: 分析和文档化 Lua 与 C++ 互调机制

## Why
项目中使用 slua_unreal 插件实现了 Lua 与 C++ 的双向调用，但目前缺乏系统性的文档来描述这一核心机制。需要创建详细的技术规范来帮助开发者理解和正确使用 Lua-C++ 互调功能。

## What Changes
- **新增** Lua 与 C++ 互调机制的技术规范文档
- **新增** 核心接口和类的说明
- **新增** 各种调用场景的使用示例
- 文档化现有实现，不涉及代码修改

## Impact
- Affected specs: 新增 `lua-cpp-interop` 能力规范
- Affected code: 无代码修改，仅文档
- 受益人群：新加入项目的开发者、需要理解 Lua 绑定机制的团队成员
