# Change: Add Windows C++ Passkey Login Demo

## Why
需要创建一个 Windows 平台的 C++ 演示程序，展示如何使用 passkey 进行登录认证。该 demo 将作为学习和测试 passkey 功能的参考实现。

## What Changes
- 添加 Windows C++ 应用程序，包含主窗口和登录按钮
- 实现 passkey 认证窗口和流程
- 创建 Visual Studio 解决方案文件（.sln）用于开发调试
- 提供完整的项目结构，支持在 Visual Studio 中编译和运行

## Impact
- Affected specs: 新增 `passkey-demo` 能力
- Affected code: 新建 C++ 项目文件、Windows API 调用、passkey 相关实现
